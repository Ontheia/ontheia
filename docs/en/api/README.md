# API Documentation

Ontheia exposes its functionality entirely over HTTP — the WebUI is just one client of it.

- **[API Reference](./01_api-ref.md):** All endpoints with parameters, response formats and authentication.
- **[Dry-Run Mode](./02_dry_run.md):** Simulate runs without executing tools or writing entries.
- **[Example script](../../de/api/dry_run_example.sh):** A runnable dry run via `curl` (the script itself is language-neutral and lives in the German tree).

Related: [Configuration API](../configuration/05_api_reference.md) for settings, [Auth Baseline](../security/03_auth-baseline.md) for sessions and tokens.

# API-Dokumentation

Ontheia stellt seine Funktionen vollständig über HTTP bereit — die WebUI ist selbst nur ein Client davon.

- **[API-Referenz](./01_api-ref.md):** Alle Endpunkte mit Parametern, Antwortformaten und Authentifizierung.
- **[Dry-Run-Modus](./02_dry_run.md):** Läufe simulieren, ohne dass Werkzeuge ausgeführt oder Einträge geschrieben werden.
- **[Beispielskript](./dry_run_example.sh):** Ausführbarer Dry-Run über `curl`.

Verwandt: [Konfigurations-API](../configuration/05_api_reference.md) für Einstellungen, [Auth-Baseline](../security/03_auth-baseline.md) für Sessions und Token.
